04 / HELP CENTRE

Good questions.
Clear answers.

Here are a few things to know while DEVPAGES is being prepared for launch.

How do I get a Pages address? +

Create a DEVPAGES account, connect your own Cloudflare account, and enter your preferred name in your dashboard. DEVPAGES asks Cloudflare to create the actual Pages project before checkout.

Does a valid name mean it is available? +

No. A name can follow the correct format and still be taken. DEVPAGES checks the real name with Cloudflare during project creation. If it is already in use, you will be asked to choose another name before checkout.

Can I connect my Cloudflare account? +

Yes. Connect securely from your DEVPAGES dashboard and approve the requested permissions on Cloudflare. Your website project is created in the Cloudflare account you connect. Never share your Cloudflare password or API token in a message.

When do I pay? +

For non-promotional accounts, DEVPAGES checks the name with Cloudflare first. Checkout is offered only after Cloudflare successfully creates the Pages project. Payment processing is being tested before general release.
